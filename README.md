# 예산 사용 관리

팀 → 단위사업 → 세부사업별로 예산과 집행 내역을 관리하는 웹 앱입니다. 구글 시트를 저장소로 쓰고 Apps Script 웹 앱으로 화면을 띄웁니다.

- 첫 화면에 팀 폴더가 보이고, 누르면 그 팀의 세부사업별 예산·집행액·지출액·남은 예산이 나옵니다.
- 위쪽 버튼으로 연도를 바꿉니다. 예산은 세부사업·연도마다 넣습니다.
- 이호조 [지출집행현황(품의)] 엑셀을 올리면 품의 단위로 묶어 집행내역에 넣습니다(다시 올리면 갱신).
- 직접 입력, 집행내역 검색, 엑셀로 받기.

## 파일

| 파일 | 설명 |
|---|---|
| `Code.gs` | Apps Script 서버 코드 (시트 읽기·쓰기, 남은금액 계산) |
| `App.html` | 웹 화면. Apps Script 밖에서 열면 샘플 데이터로 움직입니다 |
| `설치안내.md` | 설치·사용 방법 |
| `preview/` | 가상 커피숍 데이터로 움직이는 미리보기 (`index.html`을 브라우저로 열기) |

미리보기와 이 저장소에는 실제 기관 자료가 들어 있지 않습니다. 실제 집행 자료는 각자의 구글 시트에만 저장됩니다.
